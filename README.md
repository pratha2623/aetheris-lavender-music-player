# Aetheris Premium Lavender Music Player

A feature-rich desktop music player built with Python, offering playlist management, metadata extraction, audio visualizations, and a modern lavender-themed user interface.

## Features

- Playlist and queue management
- MP3, WAV, FLAC, and OGG support
- Metadata extraction using Mutagen
- Real-time search and filtering
- Shuffle and repeat playback modes
- Volume control and seeking
- Audio visualizer animations
- Custom vinyl record playback animation
- Modern GUI built with CustomTkinter

## Tech Stack

- Python
- CustomTkinter
- Pygame
- Mutagen

## Concepts Used

- Object-Oriented Programming
- Event-Driven Programming
- File Handling
- Audio Processing
- GUI Development
